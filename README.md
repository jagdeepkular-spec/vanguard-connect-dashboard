# Vanguard Connect Services Ltd — Operations Dashboard

AFL contractor operations and payroll portal. Published with GitHub Pages at
https://jagdeepkular-spec.github.io/vanguard-connect-dashboard/

## What it does

- Reads AFL's weekly settlement workbook and reconciles it to AFL's own stated total
- Prices each technician's work against their assigned pay rate card
- Produces technician pay statements and self-billed tax invoices as PDFs
- Produces the AFL invoice in AFL's required layout, with GST
- Tracks weekly and cumulative profit, and per-technician performance

## Data

No business data lives in this repository. Technicians, rate cards, settings
and history are held in a private shared workspace, reachable only with a
workspace key that travels in the share link and is never part of this page.
Opening this address without that key shows an empty dashboard.
